aframe_picoruby Examples

A-Frame のシーンを PicoRuby.wasm の Ruby で操作するサンプルです。

  • Grab Demo — マウスで図形を掴んで動かす。 掴んでいる間は白くなり、立方体の回転が止まり、視点は固定されます。ホイールで近づけたり遠ざけたりできます。 （main.rb）
  • Spin Demo — Ruby で定義した部品（AFrame::Component）で立方体を回す。 （main.rb）
  • DSL Check — シーン記述 DSL（instance_eval 型）に要る機能が PicoRuby.wasm で動くかの確認。結果はコンソールに ok / NG で出ます。 （main.rb）

各サンプルは ruby script/server で起動したサーバーから開いてください。
