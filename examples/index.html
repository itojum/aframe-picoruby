aframe_picoruby Examples

A-Frame のシーンを PicoRuby.wasm の Ruby で操作するサンプルです。

  • Grab Demo — マウスで図形を掴んで動かす。 掴んでいる間は白くなり、立方体の回転が止まり、視点は固定されます。ホイールで近づけたり遠ざけたりできます。箱の上の日本語の札（label）は、掴むと変わります。 （main.rb）
  • Spin Demo — Ruby で定義したコンポーネント（AFrame::Component）で立方体を回す。 （main.rb）
  • Garden Demo — Ruby で定義した System（AFrame::System）が花を植え、増えすぎたら古い花から抜く。 （main.rb）
  • Scene Demo — AFrame.scene のブロックでシーンを組み立てる。 （main.rb）

各サンプルは ruby script/server で起動したサーバーから開いてください。
